# Statistics Canada Table 25-10-0015-01

## Dataset

**Title:** Electric power generation, monthly generation by type of electricity  
**Publisher:** Statistics Canada  
**Table:** 25-10-0015-01  
**Frequency:** Monthly  
**Coverage:** Canada and provinces/territories; not every geography × producer × generation-type combination is available.

## Current repository extract

`data/processed/statcan_25100015_national_annual_2016_2025.csv` is a **readable national annual extract**, not the complete raw monthly table.

The values are transcribed from Statistics Canada's 2025 electricity year-in-review chart, which identifies Table 25-10-0015-01 as its source:
https://www.statcan.gc.ca/o1/en/plus/9117-electricity-generation-combustibles-and-renewables-sharply-increase-amid-another-dry-year

The extract contains annual generation for 2016–2025 in four published groupings:

- hydroelectricity
- combustible fuels
- nuclear
- wind and solar

Values are stored as **million MWh**.

## Why the extract exists

During initial project setup, repeated attempts to retrieve the full StatsCan ZIP timed out. Rather than treat an unverified partial download as raw data, the repository stores the official published annual series separately and documents its provenance.

The full monthly table remains the preferred raw dataset for the main analysis. Once retrieved successfully, it should be stored under `data/raw/` without manual edits and the transformations used to reproduce the annual extract should be implemented in code.

## Important limitation

The four published categories are too aggregated for several project questions. In particular, `combustible fuels` can include natural gas, coal, oil/diesel and biomass. The full table and/or complementary datasets will be required before making technology-specific claims about fossil generation.
